GLOBAL FLIGHT WHATSAPP LANDING PAGE - MOBILE READY
===================================================

Files:
- index.html
- airports.json

UPLOAD:
1. Upload both files into the same public hosting folder (usually public_html).
2. Make sure the file names remain exactly index.html and airports.json.
3. Open your domain in a browser.

WHATSAPP NUMBER:
Open index.html and find:
const WHATSAPP_NUMBER = "6281234567890";
Replace it with your WhatsApp number in international format, without +, spaces, or a leading 0.

MOBILE:
The page is responsive for phones and tablets. On phones, the booking button becomes a fixed bottom button and the passenger selector becomes a mobile-friendly panel.

AIRPORT DATABASE:
airports.json is loaded locally by the browser. Keep it in the same directory as index.html.

IMPORTANT:
This is a flight booking request form. It does not provide live airline inventory, live fares, ticketing, or real-time availability. It sends the customer's request to WhatsApp.
